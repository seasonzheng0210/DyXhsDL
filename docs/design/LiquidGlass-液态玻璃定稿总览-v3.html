DyXhsDL v3.0 · 液态玻璃（Liquid Glass）定稿总览

风格方向（用户裁定）：液态玻璃 · 高饱和渐变，全 App 一套语言（任务列表 / 首页下载 / 详情页 / 设置）。
相比 v2.2.0「暖调壁纸 + 白 70% 玻璃 + 纯色橙」：① 壁纸升级为高饱和液态多色渐变（亮粉彩 / 暗霓虹两套） ② 玻璃更透（白 50%）+ 1px 高光描边 + 更强 blur/saturate，呈「水珠折射」质感 ③ 主操作改液态渐变胶囊（橙→珊瑚粉）④ 圆角全面放大（卡 24 / 分段 22 / 胶囊 999）。布局与信息架构（R1-R3 任务卡、3-tab、页签）保留 v2.2.0 已验收结构，只做视觉语汇换代。
设计语言 · 三个支柱

🌊液态渐变壁纸

壁纸即光的来源。亮色 = 粉彩高饱和（薰衣草紫→蜜桃粉→雾蓝→杏橙），暗色 = 霓虹高饱和（电紫→酒红→深海蓝→琥珀）。玻璃透出的颜色随壁纸呼吸，同一玻璃块在明暗两态自动获得截然不同的氛围。

💧折射玻璃

白 50%（暗 13%）半透 + 1.5px 顶部内高光 + 1px 描边 + blur(26px) saturate(2.1)。比 v2 更透、有清晰边缘光，像一滴水覆盖在彩色底上——内容层仍以白玻璃压底保证叠字可读。

🍬渐变胶囊操作

主操作不再是纯色块：FAB / 主按钮 / 选中分段 / 开关全部使用「橙→珊瑚粉」120° 液态渐变 + 顶部高光 + 彩色投影。状态语义色也同步高饱和化（完成翠绿 / 失败珊瑚红 / 进行渐变橙）。
