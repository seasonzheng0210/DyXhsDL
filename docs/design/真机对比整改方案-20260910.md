## 二、整改项

### P0-1 手动输入对话框未玻璃化【缺陷】

- **现状**：`MainActivity.kt:2163` 仍用 Miuix `WindowDialog`。标题「手动输入链接」与副标题直接浮在任务列表上，无玻璃面板容器，文字与底层任务卡交叠（真机截图实锤）。v3.0.4 弹层玻璃化时漏改此框。
- **目标**：与清除确认弹窗同语言——居中玻璃卡（r22、亮 `Color(0xF2FFFFFF)` / 暗 `Color(0xF21E1B28)`、1px 折射描边）。
- **改法**：
  - `MainActivity.kt:2153-2215`：`WindowDialog` → 原生 `androidx.compose.ui.window.Dialog`，内容换自绘玻璃 Column（参照同文件清除弹窗 `delete_task_dialog` 的实现片段）；
  - 保留 Miuix `TextField`（r16 已合规）；
  - 「下载媒体」按钮 `TextButton` → `GlassPrimaryWrap`(r999/h40) + `Button(colors=透明, insideMargin=horizontal 12/vertical 6)`，与全 App 主按钮一致；「取消」保持 TextButton 玻璃次级样式。
- **验收**：对话框弹出时标题/输入框/按钮全部在玻璃面板内，背后列表压暗（scrim），暗色模式下描边可见。

### P0-2 输入对话框文案三平台化【缺陷】

- **现状**：副标题 `R.string.enter_xhs_url` =「输入小红书帖子分享链接」，hint「http://xhslink.com/o/...」。App 已支持抖音/快手/小红书三平台，文案误导（E2E 时实测输入抖音链接功能正常但文案说小红书）。
- **改法**：`strings.xml`（zh + values-en）
  - `enter_xhs_url` →「输入抖音 / 快手 / 小红书分享链接」（EN: "Paste a Douyin / Kuaishou / XHS share link"）
  - TextField `label` →「https://v.douyin.com/... 或 xhslink.com/...」。
- **验收**：对话框文案不绑定单一平台。

### P1-3 详情页进度数字渐变化【观感】

- **现状**：`TaskDetailActivity.kt:464` 40sp Bold 纯色橙（`OrangeTextDeep`）。
- **目标**：mockup「大字进度 = 渐变数字（液态高光）」。
- **改法**：Text 加 `style = TextStyle(brush = Brush.linearGradient(listOf(GradientStart, GradientEnd)))`，取 GlassTokens 主渐变 `#FF8A3C→#FF5F6D` 120°。
- **验收**：下载中详情页 % 数字呈橙红渐变，暗色下亮度不衰。

### P1-4 详情页进度条渐变化【观感】

- **现状**：`TaskDetailActivity.kt:478` Miuix `LinearProgressIndicator` 单色。
- **目标**：mockup 全宽橙渐变条（h8/r4 已合规）。
- **改法**：自绘：外层 Box(h8/r4/玻璃底 20% 白) + 内层 Box(`fillMaxWidth(progress)` + `Brush.linearGradient(GradientStart→GradientEnd)` + r4)。进度动画用 `animateFloatAsState`。
- **验收**：进度条橙红渐变，0% 时只剩玻璃底轨。

### P1-5 详情页顶栏对齐 mockup【观感】

- **现状**：`TaskDetailActivity.kt:293` Miuix `TopAppBar`，左箭头 + 左对齐大标题「任务详情」。
- **目标**：mockup——圆形玻璃返回钮（左上）+ 居中「任务详情」标题，无大标题。
- **改法**：换自绘顶栏（参照 `MainActivity.kt:1323` 居中标题实现）：Row[statusBars padding + h56]：左侧 36dp 圆形玻璃钮（`.border` 折射 + Icon ArrowBack）+ `weight(1f)` 居中 Text 16.5sp SemiBold。
- **验收**：三态详情页顶栏与 mockup 一致；返回功能不变。

### P2-6 完成卡缩略图行末位「保存/重下」橙钮【功能补全】

- **现状**：`MainActivity.kt:2468` 缩略图 Row 只渲染媒体格。mockup 完成卡缩略图行末位有橙色圆形下载箭头钮（保存/重新下载入口）。
- **改法**：缩略图 Row 末尾追加 52dp 圆形 `GlassPrimaryWrap` 按钮（Icon Download）：点击行为 = 有 filePaths 时调系统「保存到相册」/ 或重下（`onRetry` 语义）。建议先做「重新下载」语义（复用 onRetry），保存到相册另立项。
- **验收**：完成卡缩略图行末位出现橙渐变圆钮，点击触发重下并转下载中态。
- **备注**：此项 mockup 仅亮版样张出现一次，语义需与小郑大人确认（重下 or 保存到相册）后再动手。

### P2-7 完成卡无缩略图兜底【健壮性】

- **现状**：`task.filePaths` 为空（数据迁移/文件被清理）时完成卡只剩文本，与 mockup「完成卡必有缩略图行」观感不符；文件被删后 `rememberThumbnail` 返回 null 渲染空白格。
- **改法**：① `filePaths` 映射 MediaItem 前过滤 `File(it).exists()`；② 过滤后为空则不渲染缩略图行（现状行为，合理）；③ 空白格不渲染（bitmap null 时跳过该格而非留白）。
- **验收**：文件被删的完成卡不出现空白缩略格。

### P3-8 底部 dock 选中胶囊浓度微调

- **现状**：`MainTabBar` navOnBg 亮 70% 白 / 暗 25%；CSS `.nv.on` 亮 55% / 暗 16%。
- **改法**：`navOnBg` 亮 `0x8CFFFFFF`（55%）/ 暗 `0x29FFFFFF`（16%）；同步补 `.nv.on` 的 `box-shadow: inset 0 1px 0 rgba(255,255,255,.9)` 顶高光（可用 1dp 顶内描边模拟）。
- **验收**：dock 选中胶囊与 mockup 亮度一致。

### P3-9 设置页末项可完全露出验证

- **现状**：dock 压内容为设计态（代码注释明示）；`SettingsActivity.kt:403` embedded bottom padding = 20+navBars+110。
- **改法**：不改代码，E2E 滚到底验证「关于」组末项（项目主页）能完全滚出 dock 之上；若不能，padding 110→130。
- **验收**：滚到底时末项文字无遮挡。
