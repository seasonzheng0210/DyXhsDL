视觉基线稿 v0.2 · 分级按钮 + 玻璃只留控制层

v0.1 定的方向（低饱和玻璃 + 补顶面层）不变，本稿把四项决定落成可执行规格： 分级放大（主 CTA 60 / 次级 52 / 图标 48 / FAB 56）· 按压态与形状形变 · M3E 五档尺寸 · 统一图标体系 · 玻璃只留控制层。 拇指热区不动 —— 现有主 CTA 在底部操作条、dock 在底、FAB 右下，本来就落在自然区。
★最关键的一处结构变化：照 Apple HIG 材质指引「不要在内容层中使用 Liquid Glass」， 把玻璃收进控制/导览层（dock / 顶栏 / FAB / 开关 / 分段 / 常驻操作条）， 内容层一律换成实心标准材质（卡片 / 统计格 / 计划卡 / 缩略图）。这直接根治了 「6 级 alpha、5 级挤在 12 个百分点内」那个病。开关与滑块是 Apple 明确列出的例外，仍保留玻璃。

依据均为官方一手：Apple HIG 按钮/材质、Material 3 Buttons、 Google 无障碍触摸目标。二手参考：M3 Expressive（五档尺寸）、NN/g（主 CTA ≈2cm）、Hoober（拇指热区）。

1 · 材质分配表（这次重设计的结构改动）

左列是层，右列是该层用哪种材质。玻璃只出现在「控制与导览」和「瞬态交互控件」上。

2 · 按钮阶梯（分级放大）

层级靠颜色与形状表达，不靠大小 —— Apple HIG 明确：「将两个不同大小的按钮放在一起 可能会让界面看起来令人困惑且不一致」。所以只有主 CTA 涨到 60dp，次级保持 52dp。

M3 Expressive 五档尺寸（框架取自官方，逐档 dp 自行定档）

M3E 把按钮扩到 XS/S/M/L/XL 五档并支持 round/square 两形，按压时形状形变。 官方未逐档公布 dp 值，这里按「48dp 触摸底线 + 视觉层级」自定档，并让 L1 = XL。

按压态三态对照

Apple HIG 要求「始终为自定义按钮包括按压状态」。按下时：全圆角 30 → 26（方圆）、 缩放 0.975、内阴影加深，120ms 进入 / 180ms 回弹。

3 · 图标体系

现状是 14 个 Miuix 图标 + 自绘 .sw/.ck/.step 混用， 没有统一规格。这里定一套 24dp 网格、2dp 线宽的规格，并列出缺的功能图标。

任务列表 / 主页就绪 S2 / 调整面板 S3 / 选片页 S4。
