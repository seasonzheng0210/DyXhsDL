视觉基线稿 v0.1 · 低饱和玻璃 + 补顶面层

已定方向：保留液态玻璃但收干净 —— 壁纸降饱和、表面 6 级 → 3 级（chrome / card / top）、 文字 5 级 → 3 级、新增实心 SurfaceTop 解决浮层穿透。以下三套是同方向下的配色变体， 结构、组件、规格完全一致，只换壁纸色调 / 品牌色 / 表面三级的取值。
本页刻意不使用 backdrop-filter。浏览器里加模糊很容易，但 Compose 渲染不出来 —— v3.1.7 的 sheet 穿透就是照搬了「白 62% + blur」才出的事。所以三套稿里所有表面都是纯色叠加， 必须靠壁纸降饱和来撑住层次。
另外：暗色下品牌色与语义色一律换高亮变体 —— 深色压近黑底只有 2~3:1，这是 v3.1.4 已经踩过的坑。壁纸降饱和不只是审美选择，是没有模糊时唯一能做出层次的前提。
